<img width="1442" height="349" alt="image" src="https://github.com/user-attachments/assets/ed136113-97db-4755-b6f2-e7ff9d0f8e43" />

Program Java ini dibuat untuk menghitung biaya kirim paket berdasarkan berat, jarak, dan ukuran paketnya. Kalau data belum dimasukkan lewat argumen, program akan meminta pengguna mengetikkannya satu per satu. Setelah itu, program menghitung volume paket, menentukan tarif per kilogram (Rp 4.250 kalau jaraknya sampai 10 km, atau Rp 6.000 kalau lebih jauh), lalu menambah biaya ekstra Rp 50.000 jika volume paket lebih dari 100 cm³. Terakhir, program menampilkan rincian lengkap seperti berat, jarak, tarif, dan total biaya kirim dalam bentuk rupiah.

Program Java ini berfungsi untuk menentukan apakah sebuah bilangan genap atau ganjil. Pengguna diminta memasukkan satu bilangan bulat, lalu program akan mengecek apakah input tersebut valid. Jika bukan angka bulat, program memberi pesan error. Kalau valid, program memeriksa apakah bilangan itu habis dibagi 2, kalau iya berarti genap, kalau tidak berarti ganjil. Hasilnya kemudian ditampilkan ke layar.

Soal 2 Nomor 1
<img width="1453" height="433" alt="image" src="https://github.com/user-attachments/assets/cbdb6dcc-5767-494e-9f83-78c02f84729a" />

Program Java ini digunakan untuk menghitung faktorial dari suatu bilangan bulat non-negatif. Pengguna diminta memasukkan angka, lalu program akan mengecek apakah angkanya valid dan tidak negatif. Jika angkanya negatif, program menampilkan pesan bahwa faktorial tidak bisa dihitung. Jika valid, program akan menghitung hasil faktorial dengan cara mengalikan angka dari 1 sampai n, menggunakan tipe data BigInteger supaya bisa menampung hasil yang sangat besar. Terakhir, program menampilkan hasil faktorial ke layar.

Soal 2 Nomor 2
<img width="1448" height="441" alt="image" src="https://github.com/user-attachments/assets/6b7a8c06-5a18-47c4-873d-86f9e5f1806a" />

Program Java ini digunakan untuk menghitung volume tabung. Pengguna diminta memasukkan jari-jari (r) dan tinggi (t) tabung. Jika salah satu nilainya negatif, program akan memberi pesan bahwa nilainya harus nol atau lebih. Kalau valid, program menghitung volume dengan rumus π × r² × t menggunakan metode volumeTabung, lalu menampilkan hasilnya dengan empat angka di belakang koma.

Soal 3 Nomor 1
<img width="1453" height="440" alt="image" src="https://github.com/user-attachments/assets/f0632874-4fd1-4a4f-990a-32d975cbc83c" />

Program Java ini digunakan untuk menghitung rata-rata nilai siswa. Pertama, pengguna diminta memasukkan jumlah siswa, lalu program akan meminta nilai masing-masing siswa satu per satu. Semua nilai dijumlahkan, kemudian dihitung rata-ratanya dengan cara total nilai dibagi jumlah siswa. Terakhir, program menampilkan jumlah siswa, total nilai, dan rata-rata nilai dengan dua angka di belakang koma.

Soal 3 Nomor 2
<img width="1454" height="443" alt="image" src="https://github.com/user-attachments/assets/5b202353-a531-42ab-b906-de4b6ce046af" />

Program Java ini berfungsi untuk menjumlahkan dua matriks dengan ukuran yang sama. Pertama, pengguna diminta memasukkan jumlah baris dan kolom matriks. Jika input tidak valid atau bernilai nol/negatif, program akan berhenti. Setelah itu, pengguna mengisi elemen-elemen matriks pertama dan kedua. Program lalu menjumlahkan elemen yang posisinya sama dari kedua matriks dan menyimpannya ke matriks hasil. Terakhir, program menampilkan hasil penjumlahan matriks tersebut ke layar.
